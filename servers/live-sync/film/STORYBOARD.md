- 배경 레이어(항상): 화면 가장자리 비네팅 + 아주 옅은 SVG 노이즈 그레인(불투명도 ~4%, 매 프레임 seed 바꿔 지글거림).
- 조명 2종:
  - **로고 씬**: 화면 중앙 따뜻한 방사형 글로우(아주 약함).
  - **본문 씬(9초~)**: 오른쪽 위에서 비스듬히 내려오는 금빛 사선 빔(블러 큰 그라디언트). 천천히 호흡(불투명도 0.6↔1, 6초 주기).
- 장면 전환: 대부분 0.4~0.6초 페이드아웃 → 0.2초 암전 → 다음 장면. 텍스트 등장은 "블러 12px + 아래 12px + 불투명 0 → 선명" 0.6초 ease-out. 줄·요소는 0.2~0.3초 간격 스태거.

### S1 로고 인트로 0.0–8.4
레이아웃(1920 기준): 중앙 정렬 3줄. `OFF`(금, 약 220px) 옆 위에 작은 `THE`(크림, 약 110px), 2줄 `RECORD`(금, 220px), 3줄 `SALON`(크림, 220px). 자간 넓게.
- 0.0–0.4 암전, 중앙 글로우만 서서히.
- 0.4 `OFF` 블러 인 → 0.6 `THE` → 0.8 `RE…CORD` 글자별 왼→오 스태거 블러 인 → 1.0 `SA…LON` 같은 방식. 1.4에 완성.
- 1.8 하단 라벨 `REPIUM LAB PRESENTS  /  SEASON 01` (모노, 회색, 22px) 페이드 인.

- 4.0–4.8 전체가 살짝 어두워졌다(0.6) 다시 밝아짐(호흡).
- 5.0 `SALON`이 어두운 회색(불투명 0.25)으로 가라앉고, `OFF THE RECORD` 블록에 **모서리 브래킷 4개**(L자, 1px 크림, 30px)가 바깥에서 안으로 모이며 등장 + 금색 글로우 강해짐. `RECORD`와 `SALON` 사이에 가는 가로선 + 가운데 ◇.
